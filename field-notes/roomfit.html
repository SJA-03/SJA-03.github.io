CHAPTER 01 / AI × SPACE

RoomFit.

2026팀 프로젝트 · SW부문 우수상·인기상

가구 수정 요청을 해석하고,
배치가 가능한지 확인하기

방을 스캔하고 가구 배치를 편집하는 팀 프로젝트입니다. 저는 자연어 수정 요청을 해석하고, 배치 수정과 조건 검사로 연결하는 작업에 참여했습니다.

01

핵심 문제

책상을 키웠을 때, 다른 가구와 겹치면 안 됩니다.

요청에서 바꿀 가구와 크기를 정확히 알아내는 것과, 바꾼 가구가 방 안에 들어가는지는 별개의 문제였습니다.

이해해야 할 것

어떤 가구를 어떻게 바꾸려는가

확인해야 할 것

충돌·경계·동선 조건을 만족하는가

02

내 역할

수정할 대상과 내용을 배치 연산에 연결했습니다.

내가 맡은 일

  • 요청의 수정 대상·내용·제약을 정리하는 작업에 참여
  • 해석한 요청을 배치 수정·검증으로 연결
  • AI가 해석할 내용과 규칙으로 검사할 조건 검토

팀의 결과

공간 스캔 앱·웹 3D 편집기·서버를 연결한 제품은 팀의 작업입니다.

03

선택과 이유

선택이유

수정 대상·내용·제약을 먼저 정리

요청 해석의 오류와 배치 수정의 오류를 나눠 확인하려고

배치를 수정한 뒤 충돌·경계·동선 검사

요청을 이해해도 가구가 실제로 들어가는지는 따로 확인해야 해서

모호한 요청 재확인·실패 시 대체 처리

요청이 불분명하거나 LLM 호출·응답 파싱이 실패할 수 있어서

해석·연산·검증 흐름 살펴보기

FEEDBACK PATH / 설명용 흐름

“책상을 더 크게”
AI / INTENT

자연어 요청에서 의도·대상·제약을 구조화합니다.

RULES / OPERATION

구조화된 의도를 규칙 기반 배치 수정으로 연결합니다.

RULES / VALIDATION

충돌·경계·동선 조건으로 결과를 확인합니다.

실제 모델 호출이나 배치 실행 없이, 자연어 수정 경로의 역할 분담을 보여줍니다.

자연어 수정 경로에 관한 설명입니다. 현재 코드에는 LLM이 좌표를 직접 제안하는 선택적 경로도 있습니다.
